## 一、现有视频创作流程全景

### 当前四步流程

```
Phase 0: 定结构 (导演层)  →  从10种叙事蓝图中选1种
Phase 1: 定表达 (编剧层)  →  选表达模板 + 填Brief + 可选热点 + AI生成3条文案
Phase 2: 定包装 (包装层)  →  选闪剪包装模板 + 配素材 + BGM
Phase 3: 出视频 (生成层)  →  选数字人/声音 + 提交渲染
```

### 核心代码

| 模块 | 文件 | 规模 |
|------|------|------|
| 创作主页 | `apps/web/src/app/(dashboard)/create/page.tsx` | 157KB 单文件 |
| 叙事结构 | `apps/web/prisma/seed-structures.ts` | 10种结构 |
| 文案引擎 | `apps/web/src/lib/script-generator.ts` | 3步LLM流水线 |
| 热点系统 | `apps/web/src/lib/hot-topic-intelligence.ts` | 抖音热榜+适配评估 |

### 问题诊断

1. **"定结构"不是导演** — 用户从10个抽象叙事蓝图选择，但模板渲染无法控制镜头语言
2. **缺"拍什么"** — 小白用户最需要AI帮想选题，而非选择"反差钩子法"vs"悬念递延法"
3. **文案缺精细化框架** — 开头/结构/结尾组合是爆款核心骨架，目前全由LLM内部决定
4. **热点融合弱** — 热点仅作为可选注入，缺乏对比选择和主动驱动

## 二、新流程设计（六专家共识）

### 新四步流程

```
Phase 0: 选题 (策划层)     →  AI从12大元素库组合生成4个选题卡片，用户选1个
Phase 1: 定文案 (编剧层)   →  选开头(7种)+结构(9种)+结尾(4种)+热点融合 → AI生成
Phase 2: 定包装 (包装层)   →  不变
Phase 3: 出视频 (生成层)   →  不变
```

### Phase 0: 选题 — 关键设计决策

| 决策点 | 结论 | 来源 |
|--------|------|------|
| 触发方式 | **自动生成**（进入Phase 0即触发），无需按钮 | 产品经理 |
| 「换一批」限制 | 无硬限制，心理冷却（3次后提示"已优化结果"） | 产品经理 |
| 卡片信息 | 标题(≤20字) + 元素标签(1-2个) + 推荐开头 + 推荐结构 + 一句话理由 | UI/UX + 产品 |
| 自定义入口 | 有，刷新≥4次后引导或用户主动点击 | 产品经理 |
| 选题AI模型 | Claude Sonnet 4.6, temp=0.7, 预估1.3-2s | AI专家 |
| 元素随机策略 | 每次抽取2-3个，有冲突矩阵过滤 | 营销专家 |

### Phase 1: 文案 — 关键设计决策

| 决策点 | 结论 | 来源 |
|--------|------|------|
| 信息架构 | **分层设计** — 默认展示AI推荐组合，用户可展开自定义 | 产品经理 |
| 选择器形态 | Tab组件（开头/结构/结尾三Tab），每个Tab内卡片选择 | UI/UX |
| 预填策略 | 选题卡片推荐自动预填，80%用户不改 | 产品经理 |
| 热点融合 | 默认关闭，用户opt-in | 产品经理 |
| A/B对比 | 桌面左右分屏，手机Tab切换 | UI/UX |
| 双版本生成 | Promise.all 并行，总耗时5-7s | AI专家+架构师 |
| 评分新维度 | +openingFormulaCompliance +endingTypeCompliance | AI专家 |

## 三、12大元素库营销评估（营销专家）

### TOP 5 爆款组合

| 等级 | 组合 | 爆款指数 | 适用范围 |
|------|------|---------|---------|
| S级 | 利益前置(1)+极限对比(2)+动作钩子(9) | 8.5/10 | 电商/效率/知识付费 |
| S级 | 痛点直击(3)+真实信任(11)+互动参与(12) | 8.2/10 | 美妆/餐饮/生活方式 |
| S级 | 身份共鸣(5)+猎奇反常(6)+情感驱动(8) | 8.0/10 | 社区/教育/垂直兴趣 |
| A级 | 成本极限(4)+借势背书(7)+节奏密度(10) | 7.8/10 | 教育/SaaS/健身 |
| A级 | 反差对比(2)+身份共鸣(5)+情感驱动(8) | 7.6/10 | 个护/时尚/心理 |

### 元素冲突矩阵（禁止组合）

- 成本极限(4) × 借势权威(7) — 便宜+权威自相矛盾
- 猎奇反常(6) × 真实信任(11) — 夸大与真实感冲突
- 情感过度(8) × 成本强调(4) — 情感决策vs理性价格
- 借势权威(7) × 身份共鸣(5) — "我比你专业"vs"我们一样"

### 行业适配矩阵

| 行业 | TOP3元素 | 避免 |
|------|---------|------|
| 电商 | 利益(1)/极限(2)/成本(4) | 猎奇反常(6) |
| 教育 | 痛点(3)/身份(5)/借势(7) | 过度情感(8) |
| 美妆 | 情感(8)/真实(11)/动作(9) | 成本强调(4) |
| 餐饮 | 真实(11)/互动(12)/身份(5) | 借势权威(7) |
| 健身 | 痛点(3)/利益(1)/极限(2) | 猎奇反常(6) |

### 营销专家补充建议

1. **账号阶段策略** — 新号/成长期/成熟号应使用不同的元素+开头策略
2. **爆款指数模型** — 开头分×0.25 + 结构分×0.25 + 元素组合分×0.3 + 结尾分×0.15 + 热点加成×0.05
3. **反向检查清单** — 生成选题后自动检查翻车风险
4. **建议补充第八种开头** — "权威引入型"（作为X领域从业者X年...）

## 五、AI Prompt 工程（AI专家）

### 选题生成 Prompt

- **Model**: Claude Sonnet 4.6, temp=0.7, maxTokens=2000
- **输入**: IP档案(行业/痛点/人群) + 随机元素组合(2-3个)
- **输出**: JSON, 4个TopicCard, Zod验证
- **重试**: 3次, 温度递减 0.7→0.5→0.3
- **预估延迟**: 1.3-2.0s

### 文案生成 Prompt 升级

- **context block 重构**: 注入选题标题+元素 → 开头公式模板 → 结构节拍序列 → 结尾类型要求
- **meta-prompt 变更**: openingStrategy 由开头公式约束，narrativeBeats 由结构节拍指导
- **热点双版本**: Promise.all 并行生成原版+热点版（共6条），总耗时5-7s
- **评分新增**: openingFormulaCompliance(0.12权重) + endingTypeCompliance(0.08权重)

### Zod Schema

```typescript
TopicCardSchema = z.object({
  title: z.string().min(2).max(20),
  elements: z.array(z.enum([...12codes])).min(1).max(3),
  openingType: z.enum([...7codes]),
  recommendedStructure: z.enum([...9codes]),
  rationale: z.string().min(10).max(200),
})
TopicGenerationResponseSchema = z.object({ topics: z.array(TopicCardSchema).length(4) })
```
