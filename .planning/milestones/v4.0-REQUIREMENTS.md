# Requirements: ClipFlow

**Defined:** 2026-04-02
**Core Value:** Small business owners with zero video production skills can produce professional marketing videos through an AI-guided pipeline that handles structure, script, and visual packaging end-to-end.

## v4.0 Requirements

Requirements for IP 档案三维定位升级. Each maps to roadmap phases.

### Data Infrastructure

- [x] **DATA-01**: IpProfile schema adds profileVersion field (Int, default 1) for dual-track compatibility
- [x] **DATA-02**: IpProfile schema adds 5 survey input fields (surveyIndustry, surveyTargetCustomer, surveyMonetization JSON, surveyPersonalTraits, surveyContentGoal)
- [x] **DATA-03**: IpProfile schema adds 3D positioning fields (business: sellWhat/sellToWhom/userPainPoints/monetizationPath; persona: expertiseLevel/expressionStyle/selfIntro/memoryTags/trustCredentials/accountSetup; content: contentPyramid/seriesDirections/differentiationAdvice/contentTags)
- [x] **DATA-04**: Dual-version buildIpProfilePromptSnapshot generates v1 or v2 snapshot based on profileVersion
- [x] **DATA-05**: Dual-version isComplete/getMissingFields logic — v1 checks 7 flat fields, v2 checks 3D positioning sections
- [x] **DATA-06**: GET/PUT /api/ip-profile returns and accepts both v1 and v2 field structures

### AI Generation

- [x] **AIGEN-01**: POST /api/ip-profile/generate-positioning accepts 5-question answers and returns structured 3D positioning JSON
- [x] **AIGEN-02**: System prompt enforces three-dimensional methodology with strict field constraints (exact counts, ratio sum = 100)
- [x] **AIGEN-03**: Zod schema validates all 3D positioning fields with type, length, and count constraints
- [x] **AIGEN-04**: Auto-fix + retry pipeline (ratio normalization, temperature reduction on retry, max 2 retries)
- [x] **AIGEN-05**: Prompt injection protection (input sanitization, XML delimiters, role anchoring)
- [x] **AIGEN-06**: Output quality gate rejects generic/boilerplate responses and triggers retry with specificity instructions

### Frontend

- [x] **UI-01**: 5-question stepper wizard with progress indicator, card-based selection for Q1/Q3/Q5, text input for Q2/Q4
- [x] **UI-02**: AI generation loading state with progressive status messages
- [x] **UI-03**: Three-card result display (Business / Persona / Content) with one-line AI summary at top
- [x] **UI-04**: Inline editing for each sub-field (click-to-edit) and Badge add/remove for tag arrays
- [x] **UI-05**: Confirm + Save and Re-generate buttons on result page
- [x] **UI-06**: First-time (wizard) vs returning (dashboard with edit buttons) mode based on profileVersion
- [x] **UI-07**: Mobile-responsive stepper (full-screen immersive, bottom sticky CTA, one question per screen)

### Integration

- [x] **INTG-01**: script-generator.ts buildContextBlock and scoreWithAI/scoreWithKeywords adapt to v2 promptSnapshot and 3D fields
- [x] **INTG-02**: hot-topic-intelligence.ts FitInput.ipProfile extended for v2 fields
- [x] **INTG-03**: brief/ai-fill and packaging-material-suggestions consume v2 promptSnapshot transparently
- [x] **INTG-04**: Legacy user upgrade entry — v1 complete users see "Upgrade IP Profile" prompt, old fields pre-fill 5 questions
- [x] **INTG-05**: /create page v1 compatibility — v1 isComplete=true users not blocked by new logic
- [x] **INTG-06**: Home page banner for v1 users (non-blocking upgrade nudge, not modal)
- [x] **INTG-07**: Quality regression validation — 5 industries A/B test v1 vs v2 promptSnapshot script generation quality

## Out of Scope

| Feature | Reason |
|---------|--------|
| Chat-based onboarding | Stepper wizard chosen for higher completion rate with low-tech users |
| IP profile version history / rollback | IP positioning is overwrite-only; no user need for rollback; audit via ContentGenerationRun.ipProfileId |
| Batch data migration script | Early-stage user count; guide users to self-serve upgrade instead |
| Streaming LLM output for positioning | JSON validation requires complete output; 3-8s acceptable with loading animation |
| 卖惨同情人/优越炫富人 persona types | Brand risk; replaced with two-dimensional model (expertise × expression style) |
