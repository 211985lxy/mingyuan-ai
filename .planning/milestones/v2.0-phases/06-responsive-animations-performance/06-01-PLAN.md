  <action>
Append the following CSS rules to globals.css AFTER the existing marketing-page block. Do NOT modify any existing rules.

The animation approach:
- Use `@keyframes fadeInUp` for section entry (translate Y + opacity)
- Apply `animation-fill-mode: both` so sections start invisible
- Use `animation-timeline: view()` with `animation-range` for scroll-triggered entry (CSS Scroll-Driven Animations, supported in Chrome 115+, Safari 18+)
- Fallback for unsupported browsers: use `@supports not (animation-timeline: view())` to provide a simple `opacity: 1` state so content is always visible
- `@media (prefers-reduced-motion: reduce)` disables all animations

```css
/* ============================================================
   Marketing — Section scroll-triggered animations
   ============================================================ */

@keyframes marketing-fade-in-up {
  from {
    opacity: 0;
    transform: translateY(24px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Apply scroll-driven animation to all marketing sections */
.marketing-page section {
  animation: marketing-fade-in-up 0.5s ease forwards;
  animation-timeline: view();
  animation-range: entry 0% entry 30%;
}

/* Fallback: browsers that don't support animation-timeline still see content */
@supports not (animation-timeline: view()) {
  .marketing-page section {
    opacity: 1;
    transform: none;
    animation: none;
  }
}

/* Respect user's motion preference */
@media (prefers-reduced-motion: reduce) {
  .marketing-page section {
    animation: none;
    opacity: 1;
    transform: none;
  }
}
```

Note: Do NOT add `animation-play-state: paused` + Intersection Observer JS patterns — use pure CSS only. The `animation-timeline: view()` is CSS-only and requires no JavaScript.
