1. Create `apps/web/src/app/(marketing)/layout.tsx`:
   ```typescript
   import { Noto_Sans_SC } from "next/font/google"
   import { getLocale } from "next-intl/server"

   const notoSansSC = Noto_Sans_SC({
     variable: "--font-noto-sans-sc",
     subsets: ["chinese-simplified"],
     weight: ["400", "500", "700"],
     preload: false,
     display: "swap",
   })

   export default async function MarketingLayout({
     children,
   }: {
     children: React.ReactNode
   }) {
     const locale = await getLocale()

     return (
       <div
         className={`marketing-page flex flex-col min-h-screen ${notoSansSC.variable}`}
         lang={locale === "zh" ? "zh-CN" : "en"}
       >
         <main className="flex-1">{children}</main>
       </div>
     )
   }
   ```
   Notes:
   - NO `<html>` or `<body>` tags — this is a nested layout, not a root layout.
   - `preload: false` on Noto_Sans_SC is CRITICAL — prevents 5-10MB eager download.
   - The `MarketingNavbar` and `MarketingFooter` are NOT added yet — they are created in Plan 02. This plan only creates the shell structure.
   - The `lang` attribute uses `"zh-CN"` when locale is `"zh"`, `"en"` otherwise.
