Create apps/web/src/lib/tikhub/adapters/douyin.ts implementing all five PlatformAdapter methods using TikHub App V3 endpoints.

## Method: resolveUrl(url: string): Promise<string>

Endpoint: GET /api/v1/douyin/web/get_sec_user_id
Params: { url }
Response data shape: { sec_user_id: string }
Returns: data.sec_user_id

If the URL already contains a sec_user_id in the path (detected via parseUrl from url-parser.ts returning a non-null rawUserId), call the API anyway — the endpoint handles all URL forms and is the canonical resolver.

## Method: fetchAccount(userId: string): Promise<NormalizedAccount>

Endpoint: GET /api/v1/douyin/app/v3/handler_user_profile
Params: { sec_user_id: userId }
Response data shape: { user: { uid, nickname, avatar_thumb: { url_list }, signature, follower_count, following_count, total_favorited, aweme_count, custom_verify, enterprise_verify_reason } }

Map to NormalizedAccount:
- platformUserId: user.uid (string)
- nickname: user.nickname
- avatar: user.avatar_thumb.url_list[0] ?? ''
- signature: user.signature ?? ''
- followerCount: user.follower_count ?? 0
- followingCount: user.following_count ?? 0
- totalLikes: Number(user.total_favorited) ?? 0  // may be string from API
- videoCount: user.aweme_count ?? 0
- isVerified: Boolean(user.custom_verify || user.enterprise_verify_reason)
- verifyInfo: user.custom_verify ?? user.enterprise_verify_reason ?? ''

## Method: fetchVideos(userId: string, count: number): Promise<NormalizedVideo[]>

Endpoint: GET /api/v1/douyin/app/v3/fetch_user_post_videos
Params: { sec_user_id: userId, count: 20, max_cursor: 0 (initial) }
Pagination: response data has { aweme_list: [...], max_cursor: number, has_more: 0|1 }

Pagination logic:
- Accumulate videos in a results array
- Continue fetching while results.length < count AND data.has_more === 1
- Pass data.max_cursor as max_cursor in next request
- Page size: 20 per request (TikHub limit)
- Hard cap: stop when results.length >= count OR has_more === 0

Map each item in aweme_list to NormalizedVideo:
- videoId: item.aweme_id
- title: item.desc ?? ''
- coverUrl: item.video?.cover?.url_list?.[0] ?? ''
- videoUrl: item.video?.play_addr?.url_list?.[0] ?? ''
- createTime: item.create_time  // already Unix seconds
- duration: Math.round((item.video?.duration ?? 0) / 1000)  // API returns milliseconds
- views: item.statistics?.play_count ?? 0
- likes: item.statistics?.digg_count ?? 0
- comments: item.statistics?.comment_count ?? 0
- shares: item.statistics?.share_count ?? 0
- collects: item.statistics?.collect_count ?? 0

Return results.slice(0, count).

## Method: fetchVideoStats(videoIds: string[]): Promise<Map<string, VideoStats>>

Endpoint: GET /api/v1/douyin/app/v3/fetch_multi_video_statistics
Params: { aweme_ids: videoIds.join(',') }
Max per call: 50 IDs. If videoIds.length > 50, split into chunks of 50 and make multiple calls.

Response data shape: { aweme_details: Array<{ aweme_id, statistics: { play_count, digg_count, comment_count, share_count, collect_count } }> }

Build result Map<string, VideoStats> keyed by aweme_id:
- views: item.statistics.play_count ?? 0
- likes: item.statistics.digg_count ?? 0
- comments: item.statistics.comment_count ?? 0
- shares: item.statistics.share_count ?? 0
- collects: item.statistics.collect_count ?? 0

If videoIds is empty, return empty Map immediately.

## Method: fetchComments(videoId: string, count: number): Promise<NormalizedComment[]>

Endpoint: GET /api/v1/douyin/web/fetch_video_comments
Params: { aweme_id: videoId, count: Math.min(count, 20), cursor: 0 }
Response data shape: { comments: Array<{ cid, text, digg_count, create_time, stick_position }> }

Map each comment:
- commentId: item.cid
- text: item.text ?? ''
- likes: item.digg_count ?? 0
- createTime: item.create_time
- isTop: (item.stick_position ?? 0) > 0

Single page only (no pagination for comments — 20 per call is sufficient per spec).
Return results.slice(0, count).

## Type safety

Define internal wire types as private interfaces within the file (not exported) for the TikHub response shapes. Use `unknown` for deeply nested optional fields and access via optional chaining.

Use `tikhubGet<DouyinProfileData>('/api/v1/douyin/app/v3/handler_user_profile', params)` pattern with typed return.

## Error handling

Do not catch errors in adapter methods — let TikHubError propagate up to the pipeline (Phase 15 handles failures).
