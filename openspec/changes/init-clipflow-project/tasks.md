## 实施策略

前端优先：先用 mock 数据完整构建所有页面和交互，跑通用户旅程。暂不实现任何后端 API、数据库、第三方集成。后端作为后续独立 change 接入。

## 1. 项目脚手架与 Mock 数据层

- [x] 1.1 初始化 Next.js App Router 项目（TypeScript, Tailwind CSS, shadcn/ui），配置 `(auth)` 和 `(dashboard)` 路由组，搭建基础 layout 和导航 shell。
- [x] 1.2 定义 TypeScript 类型（User, Avatar, Asset, Script, VideoTask）和 mock 数据集，覆盖各状态组合（如 avatar: cloning/ready/failed, task: pending/processing/completed/failed）。
- [x] 1.3 创建 mock service 层（`lib/mock/`），模拟 API 调用行为（延迟返回、状态轮转），前端通过该层获取数据，后续替换为真实 API 时只改这一层。

## 2. 认证页面

- [x] 2.1 构建登录页面，包含邮箱 + 密码表单、表单验证、登录按钮，mock 登录成功后跳转 dashboard。
- [x] 2.2 构建注册页面，包含邮箱 + 密码 + 确认密码表单，mock 注册成功后跳转登录。
- [x] 2.3 实现前端 auth 状态管理（Context/Zustand），控制已登录/未登录路由跳转。

## 3. 首页（Dashboard）

- [x] 3.1 构建首页：显著的「创建视频」主操作入口、当前套餐与剩余额度展示、最近生成的视频列表（含状态标签和缩略图）。
- [x] 3.2 最近视频卡片支持点击跳转到视频详情/预览页。

## 4. 视频创建向导（3 步核心旅程）

- [x] 4.1 **Step 1 — 输入文案**：文案输入区 + 「AI 生成脚本」按钮（输入行业/卖点/城市），mock 返回 3 条候选脚本，用户可选择、编辑、确认。
- [x] 4.2 **Step 2 — 选择数字人**：展示用户数字人列表（含封面图、名称、绑定声音信息），支持选中态，提供「创建数字人」入口跳转资产页。
- [x] 4.3 **Step 3 — 确认生成**：汇总已选脚本和数字人信息，显示预估额度消耗，「生成视频」按钮触发 mock 任务创建。
- [x] 4.4 **生成中等待态**：进度指示器（预计 30s-2min），mock 模拟轮询状态轮转（pending → processing → completed），完成后自动跳转结果页。
- [x] 4.5 向导步骤条导航，支持前进/后退，保持各步骤已填数据。
