# AIM 新媒体 IP 原生企业内部试点

## 试点边界

- 只选 1 个老板 IP、1 个主推产品、1 类主要目标客户。
- 连续 4 周，每周计划并发布 4—5 条内容。
- 飞书作为增强入口开启，每周至少完成 1 次 Web-only 全链路演练。
- 不开发应用市场多租户、企业微信商店、自动外发和复杂 CRM。

## 每周操作

1. 录入真实素材：老板经验、客户问题、会议和交付现场。
2. 在项目本周看板确认 4—5 个选题，每个选题必须有目标客户、真实问题和期望行动。
3. 用通用聊天探索不明确的内容；确定后进入母内容、内容包和人工审核。
4. 生成人工拍摄/素材交接包。没有真实交付物时不得标记生产完成。
5. 人工确认事实、数字、案例、平台和链接后登记发布。
6. 回填有效线索、预约、成交和收入；到期内容补第 7 天结果。
7. 在 results 阶段读取项目周复盘，选出可复用案例、规则和评估样本候选。

## 放行门槛

- 4 周至少发布 16 条，且 100% 有项目、来源、目标客户、经营目标、期望行动和发布链接。
- 至少 90% 内容有可追溯来源，案例和数字无无依据新增。
- 至少 80% 到期内容完成第 7 天回填。
- 至少 1 条内容形成可核对的有效线索归因。
- 从素材到可审核稿的人工活跃时间较基线下降至少 30%。
- 断开飞书后，内容、发布、结果回填和周复盘仍可完成。

## 故障处理

- 飞书 `disabled/degraded`：转网页端继续，不修改 AIM 内容状态。
- 生产供应商不可用：使用人工交接包，状态停留在 `prepared`。
- 证据不足：继续通用聊天或补素材，不进入可发布。
- 未回填结果：指标显示“待回填”，不作 0 处理。
