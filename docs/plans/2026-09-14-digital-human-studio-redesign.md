# 数字人工坊（Digital Human Studio）— 页面布局与交互设计方案

> 日期：2026-09-14
> 范围：应用导航与信息架构重构 + 数字人/音视频编辑独立模块的完整设计
> 性质：前端信息架构与交互设计（复用现有后端 API，不动服务端链路）

---

## 0. 背景与问题诊断

### 0.1 现状：数字人/音视频能力散落在 4 处

| 能力 | 现在的位置 | 问题 |
| --- | --- | --- |
| TTS 配音 / 音色克隆 / 配音历史 | `/voice-studio` 语音工坊（工具箱折叠区） | 藏得太深，与出片流程割裂 |
| 数字人形象克隆 / 授权视频 / 状态轮询 | `/assets` 资产库 avatars-tab | 形象是"数字人核心资产"，却埋在文件资产库里 |
| 一键数字人出片弹窗（选形象/音色/脚本） | AIM 对话流内 `digital-human-video-dialog` | 与主创作流混在一起，弹窗承载复杂配置，信息过载 |
| 数字人成片任务列表（状态/重试/转存） | `/videos` 我的成片 | 与生成流程分离，用户要跨页面追任务 |

同时 `/aim` 主创作台聚合了计划问答、消息流、视频链接提取、对标面板、批量文案、IP 档案、工作流记录等十余个区块，主页面过载。

### 0.2 重构目标

1. **主页面极简**：`/aim` 只保留选题与文案创作主线，音视频生产整体外迁。
2. **独立完整的数字人工坊**：新增导航入口，音频数字人与视频数字人的全部编辑操作在一个模块内闭环。
3. **极简引导式交互**：无论音频还是视频，少量连续点击即可完成复杂编辑；打开页面即知道下一步做什么。

## 1. 全局导航与信息架构重构

### 1.1 导航调整（`app-sidebar.tsx`）

| 区域 | 调整前 | 调整后 |
| --- | --- | --- |
| 主线导航 | 创作台 / 市场洞察 / 数据看板 / 我的项目 | 创作台 / **数字人工坊（新增）** / 市场洞察 / 数据看板 / 我的项目 |
| 工具箱 | 极简模式 / 爆款拆解 / 语音工坊 / 资产库 / 我的成片 / 知识库 | 极简模式 / 爆款拆解 / 资产库 / 知识库 |
| AIM 专家区 | 不变 | 不变（纯对话入口） |

要点：

- **数字人工坊是产品核心，进主线导航**（排在创作台之后第二位），不进折叠工具箱。
- 语音工坊、我的成片两个入口**从导航移除**，能力并入工坊（路由 301，见 §6）。
- 侧边栏"新建任务"按钮不变；可在其旁增加"+ 出片"快捷入口（深链视频工作台）。

### 1.2 主页面（/aim）瘦身清单

| 功能 | 处置 |
| --- | --- |
| 计划问答 / 消息流 / 文案交付 / 编辑替换 / 质检复盘 | **保留**（选题与文案主线） |
| 交付物上的「用数字人生成视频」 | 保留按钮，改为**深链跳工坊**（自动带入脚本），弹窗内复杂配置全部迁走 |
| 视频链接提取文案 / 对标文案粘贴 | **保留**（它们是选题与文案的输入方式，不是音视频生产） |
| 批量文案工作室 / IP 档案 / 工作流记录 | 保留（属文案创作域），后续可另行收纳 |

### 1.3 数字人工坊信息架构（站点地图）

```
/studio                     工坊首页 —— 模式选择 + 继续上次
/studio/audio               音频工作台 —— 引导流：选音色 → 念文案 → 出成品
/studio/video               视频工作台 —— 引导流：选形象 → 声音与文案 → 出成片
/studio/library             素材库 —— 我的音色 / 我的形象 / 公共形象
/studio/works               作品 —— 任务列表 / 进度 / 重试 / 下载 / 转存 AIM
```

工坊内部使用**独立顶栏**（不套 dashboard 侧栏的完整形态，仅保留收窄图标栏），进入工坊即进入沉浸式工作区，与"主页面极简"形成同样的心智：**一个模块，一件任务，一条流程**。

## 2. 页面布局方案

### 2.1 布局总原则

- **全幅沉浸工作区**，不是仪表盘；没有卡片墙，只有舞台 + 步骤。
- **中央舞台**：当前步骤唯一的决策区，一屏只回答一个问题。
- **底部主操作条**：主按钮唯一、常驻、高亮，永远在右下角。
- **高级设置右侧抽屉**：默认收起，全部进阶参数（语速/情绪/档位/比例/字幕/清晰度）折叠在内，不阻断主流程。

### 2.2 通用工作台骨架（音频/视频共用）

```
┌────────────────────────────────────────────────────────────────┐
│ 顶栏  ← 工坊 │ ● ① 选形象 ─── ○ ② 声音文案 ─── ○ ③ 出成片 │ [素材库][作品] │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│                中 央 舞 台（当前步骤唯一决策区）                  │
│                                                                │
│           Step1：资源卡片网格（形象/音色，含试听试看）             │
│           Step2：大号文案输入区 + 自动分段预览                    │
│           Step3：成品预览（播放器/任务卡）+ 导出动作              │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│ 底部操作条      [← 上一步]                [ 主操作：下一步 → ]   │
└────────────────────────────────────────────────────────────────┘
         （高级设置：顶栏入口 → 右侧滑出抽屉，默认全部预置值）
```

### 2.3 工坊首页（/studio）—— 模式选择

```
┌────────────────────────────────────────────────────────────────┐
│  数字人工坊                                        [素材库][作品] │
├────────────────────────────────────────────────────────────────┤
│              今天要做什么？                                       │
│                                                                │
│    ┌────────────────────┐      ┌────────────────────┐          │
│    │  🎧 音频数字人       │      │  🎬 视频数字人       │          │
│    │  文案 → 有声配音     │      │  文案 → 数字人成片   │          │
│    │  约 30 秒出品        │      │  形象开口说话        │          │
│    │  [ 开始创作 → ]      │      │  [ 开始创作 → ]      │          │
│    └────────────────────┘      └────────────────────┘          │
│                                                                │
│  继续上次                                                       │
│  ▸ 《私域成交方法论》配音 · 已完成 · 03:12      [播放] [下载]      │
│  ▸ 数字人成片 · 生成中 62%                      [查看进度]       │
└────────────────────────────────────────────────────────────────┘
```

- 两张大卡 = 唯二的入口，配一句人话说明 + 预期产出，不出现任何参数。
- 「继续上次」列出最近 3 条任务/成品，点击直达（成品→播放，任务→作品页进度）。
- 首次进入无任何素材时：卡片下方出现一行引导（"第一次使用？先用公共形象，30 秒出片"），点击直接进视频工作台且预选公共形象。

### 2.4 音频工作台（/studio/audio）

**Step 1 选音色** —— 网格卡片，默认选中上次使用的音色（高亮 ✓）：

```
│  选择音色（已默认选中你上次的「小雅」）         [全部] [我的] [公共] │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────────┐            │
│  │ 小雅 ✓│ │ 沉稳男 │ │ 活泼女 │ │  …   │ │ ＋ 克隆我的 │            │
│  │ ▶ 试听│ │ ▶ 试听│ │ ▶ 试听│ │      │ │    声音   │            │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────────┘            │
```

- 每卡 1 个试听按钮（5 秒样音）；点卡片本体 = 选中，**试听不改变选择**。
- 「克隆我的声音」→ 就地展开录音/上传二选一（复用 `VoiceCloneDialog`），完成后自动选中新音色并进入 Step 2。

**Step 2 念文案** —— 大号输入区 + 自动分段：

```
│  把文案贴进来（或从 AIM 一键带入）                    已 486 字 │
│  ┌──────────────────────────────────────────────┐             │
│  │  （自动分段预览：每段一张小卡，右侧 ↻ 单段重生成）   │             │
│  └──────────────────────────────────────────────┘             │
│  ▶ 整体试听（先生成预演音频，约 10 秒）                          │
```

- 超长文案自动分段（沿用 `segment-text` 逻辑），**逐段卡片**呈现，每段可单独试听/重生成——这就是音频编辑的主体。
- 「整体试听」= 便宜预演：只合成当前配置的音频，不满意改参数重来，**不产生任何成品任务**。

**Step 3 出成品** —— 播放器 + 三个去向：

```
│  🎧 《文案标题…》 01:32 ▶ ═══════●═══                          │
│         [ 下载 MP3 ]  [ 存入配音历史 ]  [ ↑ 升级为数字人视频 → ]   │
```

- 「升级为视频」= 携带音色 + 文案深链 `/studio/video`，只补选形象一步——音频到视频的连续性在此打通。

### 2.5 视频工作台（/studio/video）

**Step 1 选形象** —— 与音频 Step 1 同构：

```
│  选择形象（已默认选中你上次的「李老师」）        [我的形象] [公共形象] │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌──────────┐               │
│  │ 李老师 ✓│ │ 商务女  │ │ 休闲男  │ │ ＋ 克隆新  │               │
│  │ ▶ 试看5s│ │ ▶ 试看  │ │ ▶ 试看  │ │    形象   │               │
│  └────────┘ └────────┘ └────────┘ └──────────┘               │
```

- 卡片即形象首帧 + 5 秒试看；公共形象 tab 让零素材用户**当天可用**。
- 「克隆新形象」→ 授权视频录制/上传（复用 avatars-tab 现有链路与授权文案），提交后后台训练、不阻塞当前流程（当前可先用公共形象）。

**Step 2 声音与文案** —— 一屏两个小决策，主操作仍唯一：

```
│  声音：● 上次音色「小雅」 ○ 形象配套音色 ○ 我的克隆音色（横向三选一）   │
│  文案：┌────────────────────────────────┐  [从 AIM 带入]        │
│        │ （粘贴脚本，自动分段）            │                      │
│        └────────────────────────────────┘                      │
│  ▶ 音频预演（先用便宜合成试听口播，满意再出片）                    │
```

- **便宜的先试，贵的后渲**：本步只出 TTS 预演音频；数字人视频渲染（贵、慢）推迟到 Step 3 点击才触发。
- 声音三选一为 segmented control，默认「上次音色」，零配置即可下一步。

**Step 3 出成片** —— 默认即最优 + 提交：

```
│  预览：形象「李老师」 · 音色「小雅」 · 486 字 · 约 2 分钟成片        │
│  画面：竖屏 9:16 ● │ 横屏 16:9 ○     字幕：开 ● │ 关 ○             │
│                        [ 生成成片 ]（生成中可离开，完成后通知）       │
```

- 只暴露两个用户真正会改的开关：比例、字幕。其余（清晰度、档位、供应商）在高级抽屉，供应商按蝉镜主/闪剪备自动选择与降级。
- 点击生成 → 任务卡出现进度，**用户可立即离开**；完成通过侧栏角标 + 作品页提醒。

### 2.6 素材库（/studio/library）

- 三个 Tab：**我的音色 / 我的形象 / 公共形象**（公共形象与音色只读）。
- 我的音色：卡片（试听 / 重命名 / 删除）+「克隆声音」主按钮。
- 我的形象：卡片（状态徽标：训练中/可用/失败 + 重试）+「克隆形象」主按钮（授权视频录制或上传）。
- 资产库 `/assets` 的 avatars-tab 数据不动、UI 迁移至此；`/assets` 保留原始素材文件管理，两库职责分离（**工坊素材库管"可用的声音与形象"，资产库管"原始文件"**）。

### 2.7 作品（/studio/works）

- 全量任务列表：缩略图 / 标题 / 类型（音频·视频）/ 状态（排队·生成中·完成·失败·已降级）/ 供应商徽标 / 时间。
- 行内动作：播放（音频）/ 打开成片（视频）/ 下载 / **重试** / **转存 AIM**（沿用 degraded 链路）/ 重新编辑（回到对应工作台，全部选择带回）。
- 「重新编辑」是编辑闭环的关键：任何历史作品一键回到工作台原状态，改一处再出片。

## 3. 交互设计：极简引导式

### 3.1 六条设计原则

1. **一屏一事**：每个步骤只呈现一个决策点（音频选音色就只选音色），其余全部不可见。
2. **默认即最优**：默认音色/形象 = 上次使用；比例 9:16、字幕开、档位自动。主路径零配置。
3. **主操作唯一且常驻**：底部右下角唯一高亮按钮，位置全程不漂移；用户闭着眼也知道"点右下角"。
4. **便宜的先试，贵的后渲**：TTS 预演先行（秒级、免费档），数字人视频渲染永远由用户最后一次明确点击触发。
5. **高级全部折叠**：语速/情绪/档位/清晰度/供应商只在高级抽屉出现，永不阻断主流程。
6. **任务后台化**：生成即离开，进度在作品页与侧栏角标，不强迫等待。

### 3.2 核心操作路径与点击数

| # | 路径 | 点击数 | 说明 |
| --- | --- | --- | --- |
| P1 | 出音频（默认音色） | **3** | 工坊首页→「音频」→ 贴文案 →「生成」 |
| P2 | 出视频（默认形象+音色） | **4** | 首页→「视频」→（形象已默认）→ 贴文案 →「生成成片」 |
| P3 | AIM 文案一键出片 | **2** | 交付物 →「去工坊出片」（脚本带入，直达 Step 2）→「生成成片」 |
| P4 | 克隆我的声音 | **4** | Step1「克隆声音」→ 录 30 秒/上传 → 命名 → 保存并选中 |
| P5 | 克隆我的形象 | **4** | Step1「克隆形象」→ 录/传授权视频 → 提交 → 后台训练 |
| P6 | 不满意改编辑 | **2** | 试听 → 点另一张音色/形象卡（1）→ 重新生成（1） |
| P7 | 音频升级成视频 | **2** | 音频成品 →「升级为视频」→ 只补选形象 → 生成 |

所有主路径 ≤ 4 次点击，且每一步的界面都只有"一个显而易见的下一步"。

### 3.3 编辑操作映射（覆盖"音频与视频数字人的编辑操作"）

| 编辑意图 | 操作 | 成本 |
| --- | --- | --- |
| 换音色 | 点卡片即换 → 重新预演 | 2 次点击，秒级 |
| 调语速/情绪 | 高级抽屉滑杆/标签 → 预演即时反映 | 抽屉内，不离开流程 |
| 改文案 | Step 2 直接改输入区，自动重分段 | 无需重选资源 |
| 单段重做 | 段落卡 ↻，只重生成该段 | 1 次点击 |
| 换形象 | 点卡片即换（停留 Step1） | 1 次点击 |
| 改比例/字幕 | Step 3 segmented control | 1 次点击 |
| 成品重编 | 作品页「重新编辑」回到工作台原状态 | 1 次点击 |
| 失败重来 | 任务行「重试」（供应商自动降级蝉镜→闪剪） | 1 次点击 |

### 3.4 状态、异常与合规

- 任务状态机沿用现有：排队 → 生成中 → 完成 / 失败 / 降级（degraded → 提示转存 AIM）。
- 失败卡片给出**一句人话原因** + 单击重试；重试自动切换备用供应商。
- 形象克隆的授权视频流程保留现有合规授权文案与确认步骤，不作简化（合规例外，不极简化）。
- 生成中离开页面：进度持久化（沿用 `video-task-request` 轮询与 webhook 恢复链路），回来即在「继续上次/作品」看到。

### 3.5 空态与首次引导

- 无音色：默认选中一个公共音色，克隆入口弱化为卡片网格末位"+"。
- 无形象：默认 tab 落在公共形象并预选一个，顶部一行提示"先出片，回头再克隆你自己的形象"。
- 不使用弹窗教学、不使用遮罩引导——**默认值即教学**：用户第一次进来的选择就是可用的选择。
