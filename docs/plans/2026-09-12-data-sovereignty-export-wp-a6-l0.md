# WP-A6 L0 数据主权承诺 + 一键导出

> 上游：《明动AIM-竞品借鉴增量升级计划-2026-09-12》WP-A6 L0
> 红线：只导出当前绑定项目里用户自己的数据；不含密钥、向量、激活码；不做私有化部署包（L1）和单机个人版（L2）。

## 1. 改了什么

- 账户下增加「你的数据」页：写清数据归谁、怎么隔离、退出怎么带走。
- 项目级一键导出 JSON / Markdown：内容成稿摘要、知识条目、效果数据、素材引用清单。
- 素材按账号存、没有项目字段，导出里单独标明「账号级素材引用」，避免装成项目隔离。

## 2. 不做

- 不改隔离模型，不把账号改成一等实体（DEC-1 书面结论：维持项目隔离）。
- 不导出 embedding、JWT、Agent Key、渠道密钥。
- 不在本包做 docker 私有化（L1 见独立文档，且要客户合规信号）。

## 3. 验收

- 单测：`project-data-export`（只出绑定项目、截断有计数、Markdown 含承诺文案、不含密钥字段）。
- 登录用户能从账户菜单进到页面并下载文件。
- 放量级：一次真实导出演练另记。
