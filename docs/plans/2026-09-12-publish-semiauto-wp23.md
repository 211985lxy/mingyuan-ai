# WP-2.3 发布半自动

> 状态：代码完成 · 日期：2026-09-12 · 分支：`feat/wp11-outcome-autofetch`（尚未拆 PR）
> 上游：批次 2 / WP-2.3
> 红线：不自动外发平台；提醒开关默认关；作品 ID 仍由人填，填完才喂给 WP-1.1。

## 1. 改了什么

- 发布包增加结构化载荷：标题、话题、封面指引、作品 ID 预留位、抖音创作者上传页链接。
- cron `/api/cron/publish-reminder`：找出 48 小时内已发布但作品 ID 仍缺的记录。`AIM_PUBLISH_REMINDER_ENABLED` 默认关。
- 仓库里加了 systemd 单元对照，**没有在服务器 enable**。

## 2. 不做

- 不调飞书发卡片（等运维批准后再接发送通道）。
- 不替人登录创作者后台。
- 不宣称发布耗时下降 50%——那是放量验收。

## 3. 回滚

关掉 `AIM_PUBLISH_REMINDER_ENABLED`；发布包文本函数仍在，载荷可不用。
