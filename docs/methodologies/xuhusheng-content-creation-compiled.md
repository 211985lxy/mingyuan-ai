借鉴这套方法与框架，不模仿作者身份和语言口吻。方法论里的人物、业务、产品案例与假设，均不得覆盖当前项目真实资料与用户本次明确要求。

【定位】走专业个人 IP 路线（靠专业积累吸引精准用户），不走娱乐网红路线（靠表演博最大流量，成功率低不可复制）。人设三原则：内容型（先想用户愿看什么，不是先想产品多好）、专家型（强化专业可信，不靠娱乐覆盖它）、真实型（不编造故事、不扮演他人、不假装完美）。

【账号即杂志】把账号当一本视频杂志，不同栏目各司其职，不是单一视频重复。两类内容分开评判：破圈内容面向外圈看转发/关注/用户画像；转化内容讲专业产品看咨询/私域/成交。三层漏斗：破圈→专业信任→产品转化，产品内容约 20%。客户只占粉丝 0.5% 到万分之一，没有 99.5% 就没有那 0.5%，所以选题永远分两种：追求流量、追求转化。高频阅读低频购买，不要求看完就买，不过度逼单。2B 用户藏在 2C 里，2B 业务最该做视频号（朋友圈关系链）。

【破圈】破小圈不破大圈：可从产品扩到场景、生活方式、相邻议题；不碰与定位无关的争议/娱乐/私生活。判断标准不是「能不能爆」而是「爆后平台推来什么人」，宁要精准小流量，不要错误用户的大流量。

【四类故事选题】
1. 别人的故事（名人/案例/趋势）：借话题破圈但要有自己的判断，不只复述；故事画面现成、制作难度低，是冷启动最易上手的选择。
2. 自己的故事（创业/转型/失败/决定）：建立人格信任。用「72 问」向内挖具体故事：改变命运的时刻、最后悔的商业决定、最反常识的事、意想不到的失败、最果断的决定、做对了哪几件事——要具体故事和独特表达，倡导正向价值观（正直/善良/宽容），避免引发争议的道德表达。冷启动期大众不太关心素人故事、当局者迷讲不好自己，入门宜先做别人的故事。
3. 对谈/采访：连接有内容有故事的人，一次设 3-5 个话题（不讲个人史/公司史），一次能剪出 3 条以上视频，按结果决定取舍长短；采访型还能借别人的画面场景，属顶级形态。
4. 产品的故事：让有需求者转化，集中拍摄控制数量；产品类缺场景易变卖货，要叠加场景/人物/情感（工作、生活、家人、客户搭配、成长创业故事）。
选题第一原则利他：他为何愿看、得到什么、为何愿转、不买是否有价值。内容与产品可只是场景/用户/价值观关系。

【细颗粒】一条只说一件事（一个事件/观点/决定）。拒绝「行业未来在哪」这类宏大空泛选题。

【脚本生产节奏】准备 5-6 个有价值观/金句/传播点的故事 → 录制 30 分-1 小时不背稿、保持聊天状态 → 第一稿 2000-3000 字 → 第二稿约 1000 字 → 秘诀是分行排列（分行后易发现重复、无效过渡、最佳字幕句）。5W：开头优先交代 Who 和 What，别让用户看几十秒还不知讲什么。导演意识：能靠画面的不靠语言重复。夹叙夹议（故事→观点→细节→新判断）；禁纯复述、纯抒情、为高级用晦涩书面语、结尾突然拔高宏大叙事、传播内容结尾硬塞广告。语言接近日常对话。

【口播要领】做自己、口语化、侧对镜头（与观者喝茶聊天的状态）、情绪饱满自信、室内画面要精致。

【开头与标题】前几秒说清「谁发生什么」，最独特信息前置，不宏大铺垫不故弄玄虚。标题是招牌，不读正文也大致懂，不卖弄双关典故，一稿多标题择优，放手机封面检查。

【三种 IP 形态】创始人出镜 IP（主力）；节目型 IP（创始人不便出镜，如家电/调味品做家居/美食节目，另起媒体 IP 别动品牌大号）；员工矩阵 IP（从内容出发非个人表演，考虑员工能力不足/工作繁忙/动力不足，把简单事做到不简单）。

【搭团队】别指望找高手；团队会本能追随流行方法论未必适合你、会追求流量而非精准用户（效果短期难评估）。招大学生年轻人，文稿自己多参与。创始人始终深度参与方向/观点/脚本取舍——只有本人最懂经历、商业模式和表达分寸，别让团队个人风格凌驾于 IP 本人。

【禁止项】不抄爆款（学结构模式不抄具体选题文案，看长期稳定非单一爆款）；不迷信数量（不为完播率机械缩短，当长则长当短则短，但全程不能有弱段，一条原创优质胜过大量低质）。脚本阶段修改成本最低，最值得投入。

【发布运营】可多平台同步分发，先同步测试再选重点平台，不必为每平台做人设版本。评论区保持基本互动、不参与阵营争吵，观察关注者/私信者是否目标用户；创始人定期看反馈（留言和关注画像是最直接市场数据）。

【数据判断】传播内容看：是否进入预定圈层/有无自然转发关注/新增用户画像是否准确；转化内容看：是否带来有效咨询/用户是否理解产品/是否进私域或购买意向/客户质量。不能只看播放量、完播率、单条涨粉——专业内容阅读量低但可能商业价值高。

【本次创作自检】这条负责破圈还是转化、评价标准对不对？开头是否前几秒说清 Who/What？是否只讲一件事、有无宏大空泛？有无具体细节而非纯抽象观点？选题是否利他、是否与专业人设相关、会否引来错误用户？是否夹叙夹议、有无 AI 腔/套话/整齐排比/万能结尾？案例是真实可追溯还是编造的「我有个学员」？缺失关键信息是否标注待补充？

【项目适配】本项目目标用户是谁、明确不吸引谁？这一稿服务漏斗哪层（破圈/专业/转化）？本项目真实产品/案例/数据/卖点是什么（缺则标注待补充，不编造不移植方法论案例）？走创始人出镜/节目型/员工矩阵哪种形态？用户本次明确要求是什么、与方法论默认冲突时以用户为准。
