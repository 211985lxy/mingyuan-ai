# IP 文案操盘方法论核心版

> 来源：Obsidian `灵感库/00-操盘手方法论`。本文是项目内置精简版，用于文案编写智能体调用，不替代原始 Obsidian 笔记。

## 使用位置

文案生成时按这个顺序使用：

1. 先判断内容任务：流量、人设信任、线索获客、成交转化。
2. 再选择对应方法论卡片。
3. 再结合客户知识库：产品、用户痛点、人设、案例、问答。
4. 最后结合对标文案：保留原选题与中间结构节奏，但开头第一句要按当前 IP 的口吻重写，不照搬原句。

一句话原则：客户知识库决定“写谁”，操盘方法论决定“怎么写”。

## 文案内容路由

文案智能体先判断“这条内容为什么拍”，再选择写法。不要为下面四类新建独立智能体；它们是 `deep_copywriter` 内部的内容路由。

### 1. 人设信任型

目的：让用户相信“这个人靠谱、懂我、值得听”。

适合：来时路、价值观、专业经历、踩坑、工作现场、vlog。

写法：先给一个真实场景或经历，再说这个经历形成了什么判断，最后落到用户为什么可以信任你。

### 2. 观点立场型

目的：打出判断，让用户觉得“他说得不一样，而且说中了”。

适合：行业误区、反常识观点、趋势判断、老板认知、争议话题。

写法：先给明确判断，再拆普通人为什么会判断错，最后给自己的判断标准。

### 3. 问题解决型

目的：站在客户角度，把他们关心的问题和痛点讲清楚，再给自己的解决方案。

适合：痛点拆解、避坑指南、产品如何解决问题、客户常见问题答疑、方法清单。干货方法并入问题解决型，不单独拆路由。

写法：先说客户正在遇到的具体问题，再拆问题原因，最后给可执行方案或产品对应解决点。

### 4. 案例转化型

目的：用真实案例、产品过程、客户变化证明“这个方案有效”。

适合：案例拆解、成交转化、产品拍摄、前后对比、客户故事。成交转化并入案例转化型，不单独拆路由。

写法：先讲具体对象和处境，再讲采取了什么动作，最后讲结果变化、信任证据和下一步行动。

### 内容形式不是路由

内容路由 = 这条内容为什么拍。

内容形式 = 这条内容怎么拍。

常见内容形式：测评系列、挑战 xx 的一天、vlog 系列、产品实拍系列、客户问题答疑系列、案例复盘系列。

### 账号阶段

第一阶段立人设：优先人设信任型、观点立场型。

第二阶段做矩阵：优先问题解决型、案例转化型。

第三阶段做转化闭环：优先案例转化型、问题解决型。

## 局部优化指令路由

当用户不是要求新写一条内容，而是要求“优化某个局部”，不要重写整篇。先判断优化对象，再调用对应方法论。

### 开头优化

触发词：开头、前3秒、第一句话、钩子、起手、开场。

调用爆款开头库：好奇类、借势类、痛点类、极限类、恐吓类、反差类、利益输送。

七大爆款开头：

1. 好奇类：`XX 是一种什么体验？`、`如何不 XX 也能 YY？`、`如果你 XX，你会怎么样？`、`为什么别人 XX，却能 YY？`
2. 借势类：`曾经被某名人/事件影响，如今却 XX`、`某剧/热点大火，我却关心里面的 XX`、`某明星/名人都在用的 XX`
3. 痛点类：`为什么你 XX，却 YY？`、`不知道 XX 一定要 YY`、`XX 最新变化，你不会不知道吧？`
4. 极限类：`这是全网最 XX`、`一定要 XX`、`99% 的人都不知道的 XX`
5. 恐吓类：`揭秘，千万不要 XX`、`如果你再不 XX，就会 YY`、`XX 将迎来变化，赶紧 YY`
6. 反差类：`你知道 XX，却不知道 YY`、`我能 XX，却不能 YY`、`他只需要 XX，就能 YY`
7. 利益输送：`没想到 XX 就可以 YY`、`有了 XX 再也不用 YY`

输出要求：给 3-5 个可替换开头，并说明每个开头调用了哪类钩子。

### 标题优化

触发词：标题、封面标题、小红书标题、发布标题。

调用规则：利益前置、痛点直击、反差冲突、人群点名、结果承诺。

输出要求：给 5-10 个标题，标注主推版本。

### 结尾优化

触发词：结尾、收尾、评论引导、行动引导、CTA。

调用规则：关系阶梯、评论关键词、资料包、诊断入口、下一步行动。

输出要求：结尾不能硬广，必须让用户知道下一步做什么。

### 结构优化

触发词：结构、节奏、中段、展开、逻辑、太散。

调用规则：趋势机会型、问题解决型、干货速查型，以及线索获客的“问题 -> 解法 -> 方案”。

输出要求：优先保留原选题，只重排段落和推进顺序。

### 口播感优化

触发词：去AI味、口语化、像人说话、太书面、太端着。

调用规则：真人口播、人味检查、删掉空话、少用排比和总结腔。

输出要求：只改表达，不改事实和核心观点。

## 总原则

先定盘，再布道，再成交，再交付，最后入账。

每次写文案前先做 5 个内部判断，不向用户提问：

1. 这条内容是为了涨泛流量，还是为了筛选精准客户。
2. 用户是谁，他此刻正在付出什么代价。
3. 这条内容要让用户产生什么动作：关注、评论、私信、预约、成交。
4. 原对标文案里值得保留的是开头、结构、情绪，还是案例。
5. 客户知识库里有哪些产品、案例、痛点可以替换进去。

如果信息不足，使用现有上下文做合理假设并直接交付文案，不要让用户再回答开放式问题。

## 信息搜索守则（防编数据）

写文案需要引用外部事实、数据、案例时，先按下面边界决定要不要搜、能不能直接用。

必须搜索（素材不足，禁止直接写）：

1. 素材提到人名/公司名/产品名，但没有背景介绍。
2. 素材里有数字、比例、销量、排名，但没有来源。
3. 素材有案例，但细节不足以支撑结论。

不需要搜索（可直接用）：

1. 素材里有明确可信的数据源。
2. 纯观点、个人经验、主观判断（不涉及外部可验证事实）。
3. 历史对话里已经确认过的内容。

存疑即叫停：

- 出现"我推测 / 可能 / 大概"这类不确定表述时，不得擅自成稿。
- 无法核实的数据，改写为"待补充"或向用户求证，禁止编造数字、案例、来源。

## 人工确认点（人判断环节）

常规创作流默认不打断用户、直接交付（见「总原则」）。但以下三个闸门必须停下来让用户做结构化确认：每题给 2-4 个选项并允许补一句真实想法，不做开放式提问。

1. 方向闸：选题 / 母稿方向确认，承接「深度文案母稿」的「观点确认卡」，确认后再往下走，避免写半天方向错。
2. 事实闸：信息搜索 / 事实存疑时，把不确定项列出向用户求证，或标"待补充"，不擅自拍板。
3. 发布闸：对外发布前，把标题、关键数据、敏感表述列出，等用户确认后再发布（呼应「对外发布必须保留人工审批」）。

## 发布安全否决层（独立于质量评分）

发布前先过安全闸，任一命中即一票否决（判不及格），不进后续去AI味 / 价值 / 传播评分，也不进入发布流程：

- 政治敏感、违法违规内容
- 虚假信息、编造数据 / 案例 / 来源
- 侵权（盗用他人作品、商标、肖像、商业机密）
- 法律 / 合规风险

命中即停止发布，标注问题点，交回用户处理。

## 方法论卡片 1：流量型视频

适用场景：起号、破圈、扩大曝光、让更多目标人群第一次认识你。

核心判断：流量型视频不是炫技巧，而是用更低理解成本换取更高停留。

写作结构：

1. 用强开头制造停留：好奇、反差、痛点、恐吓、利益。
2. 用一个具体场景承接，不要直接讲大道理。
3. 把抽象观点翻译成一个小招数、一个动作、一个判断标准。
4. 中段制造断裂感，不要顺理成章一路讲到底。
5. 结尾留下评论点或关注理由。

常用开头：

- 好奇类：`为什么别人做 XX 很快起量，你却一直卡住？`
- 痛点类：`如果你现在还在 XX，大概率不是努力不够。`
- 反差类：`你以为 XX 是关键，其实真正决定结果的是 YY。`
- 恐吓类：`千万不要在 XX 没想清楚之前就开始投流。`
- 利益类：`只改这一个动作，内容转化会明显不一样。`

禁忌：

- 一上来介绍自己。
- 只讲行业大道理，没有具体场景。
- 每条都“三点式”，节奏太像课件。
- 为了流量牺牲目标用户，吸来一堆不买单的人。

## 方法论卡片 2：线索获客视频

适用场景：高客单服务、咨询、陪跑、招商、企业服务、非标项目。

核心判断：线索获客视频不是为了爆款，而是让有真实问题、真实投入、真实付费意愿的人主动找你。

底层结构：

1. 明确服务价值：到底帮谁解决什么高价值问题。
2. 定位精准客户：有筹码、有代价、有决策压力。
3. 提炼买点：从买家生活场景和情绪出发。
4. 找需求引爆点：用户从“想解决”变成“必须解决”的瞬间。
5. 设计获客内容：问题、解法、小方案。
6. 用长内容建立信任：完整呈现服务逻辑。
7. 私域承接：朋友圈、话术、诊断、发售节奏。
8. 产品阶梯：咨询、陪跑、联营、复购、转介绍。

单条视频结构：

1. 先说客户正在付出的代价。
2. 再说大多数人误判了什么。
3. 给一个小切口判断标准。
4. 放一个案例或场景，证明你见过这类问题。
5. 结尾给轻行动：评论关键词、私信、领取清单、预约诊断。

判断一条线索视频是否有效：

- 这条视频有没有说清楚我帮谁？
- 这个人看完知不知道我能解决什么？
- 这个问题是不是他愿意付钱解决的问题？
- 他看完以后有没有理由来找我？

禁忌：

- 只追播放量，不筛选人。
- 把高客单服务写成低客单带货话术。
- 内容没有私域承接动作。
- 没有产品阶梯，线索来了也接不住。

### 获客短视频方法论

获客短视频的任务不是让所有人喜欢，而是让目标客户在某个具体问题上意识到：这个人懂我、见过这类问题、可能帮得上我。

写之前先做 5 个判断：

1. 目标客户是谁：行业、身份、阶段、预算或决策权。
2. 触发场景是什么：他在哪个时刻开始着急、犹豫或想找人问。
3. 当前代价是什么：继续拖着会损失钱、时间、机会、确定性还是信任。
4. 信任障碍是什么：他不咨询，是因为怕贵、怕没用、怕被割、怕暴露问题，还是不知道自己适不适合。
5. 承接动作是什么：评论关键词、私信、领清单、预约诊断、进私域或报名。

常用选题结构：

1. 代价提醒型：先说不解决正在付出的代价，再给一个判断标准。
   - 句式：`如果你现在还在【错误做法】，真正亏掉的不是【表面损失】，而是【更深代价】。`
2. 误区纠偏型：指出目标客户普遍误判，再给更准确的方向。
   - 句式：`很多【目标客户】以为问题出在【A】，但我见过更多情况，其实卡在【B】。`
3. 自检清单型：给 3 个信号，让用户判断自己是不是该行动。
   - 句式：`如果你中了这 3 条，先别急着【常见动作】，你更该先处理【核心问题】。`
4. 案例场景型：讲一个相似客户的处境、错误选择和转折。
   - 句式：`前段时间有个【客户类型】来找我，他的问题不是【表象】，而是【真实卡点】。`
5. 筛选人群型：明确谁适合、谁不适合，提升线索质量。
   - 句式：`这条视频只适合三类人：第一类...第二类...第三类...`
6. 小方案型：给一个可执行的小动作，让客户感受到专业度。
   - 句式：`你先别做完整方案，先把这一步改掉，结果会清楚很多。`
7. 诊断入口型：把复杂问题收束成一个低摩擦动作。
   - 句式：`如果你不确定自己卡在哪，可以先把【关键信息】发我，我帮你看第一步该调哪里。`

结尾承接原则：

- 低客单可以直接引导购买；高客单优先引导诊断、咨询、清单、私域关系。
- 不要每条都喊“私信我”，要说明私信后能得到什么。
- 行动引导只保留一个，不要同时评论、私信、扫码、报名全都要。

## 方法论卡片 3：人设信任视频

适用场景：老板 IP、专家 IP、顾问型账号、需要建立长期信任的账号。

核心判断：人设不是自我介绍，而是让用户相信“这件事找你靠谱”。

写作结构：

1. 从一个真实处境切入，不要说“大家好我是某某专家”。
2. 顺带露出经历、结果、失败、判断，而不是硬摆资历。
3. 表达一个稳定价值观。
4. 用故事或案例传递背书。
5. 结尾让用户知道你长期站在哪一边。

可用素材：

- 创始人踩过的坑。
- 客户真实反馈。
- 行业里你不认同的现象。
- 一个你长期坚持的判断。
- 一次失败后的复盘。

禁忌：

- 直接堆头衔。
- 每条都像品牌宣传片。
- 完美、正确、没有瑕疵。
- 没有具体人、具体事、具体代价。

## 方法论卡片 4：成交转化视频

适用场景：产品说明、活动报名、诊断预约、课程/咨询/陪跑转化。

核心判断：成交视频不是强行推销，而是帮用户判断“我现在要不要行动”。

写作结构：

1. 先指出错误选择的代价。
2. 再明确谁适合、谁不适合。
3. 讲清产品解决什么，不要只列功能。
4. 用案例证明结果。
5. 给出低摩擦行动路径。

必须说清楚：

- 适合谁。
- 不适合谁。
- 解决什么具体问题。
- 用户现在不解决会继续损失什么。
- 下一步怎么做。

禁忌：

- 只讲优惠，不讲为什么现在需要。
- 只讲功能，不讲结果。
- 所有人都适合。
- 结尾路径太复杂。

## 方法论卡片 5：深度文案母稿

适用场景：用户提供一个想法、视频原文、老板口述、对标文案或零散观点，需要先打磨成一篇可拆分复用的深度母稿，再做多平台分发。

核心判断：深度母稿不是直接出平台文案，而是先把选题、观点、结构、钩子、表达态度和可借势热点打磨清楚。母稿质量决定后续短视频、朋友圈、公众号、小红书和私域话术的质量。

交互原则：人设性视频、观点型视频、老板口述和对标文案改造，默认先问后写。问题不能变成填空作业，每题给 2-4 个选项，并允许用户补一句真实想法。

工作顺序：

1. 先判断选题：这个话题是否同时满足“我想讲”和“用户想看”。
2. 找情绪波动：用户为什么高兴、焦虑、难受、憋屈、兴奋或不服。
3. 找热点接口：判断能否自然融合用户提供的热点、上下文里的行业趋势或明确可用的时代情绪，禁止硬蹭或编造。
4. 共创观点：先问 3-5 个半开放选择题，挖出用户真实判断、经历和态度，不要直接要成稿。
5. 先出大纲：把信息推进顺序调到“这个 IP 真的想讲”。
6. 打磨钩子：优先优化第一句话和前 3 秒，决定用户是否愿意继续听。
7. 形成母稿：把 AI 的结构能力和人的态度、经验、表达欲结合起来。
8. 再拆平台：母稿完成后，才拆成短视频、朋友圈、公众号、小红书结构和私域话术。

母稿输出结构：

1. 选题判断：这个话题为什么值得讲。
2. 观点挖掘题：3-5 个半开放选择题，每题 2-4 个选项，允许补一句真实想法。
3. 观点确认卡：确认用户选择后的真实态度、核心判断和可融合热点。
4. 内容大纲：按用户理解顺序组织，不要流水账。
5. 开头钩子：给出 2-3 个第一句话版本，标注推荐版本。
6. 深度母稿：完整表达观点、案例、情绪、热点借势点和行动方向。
7. 可拆分方向：说明后续能拆成哪些平台内容。

禁忌：

- 一上来就让 AI 直接写最终稿。
- 只追求“完整”，没有情绪和态度。
- 大纲没调好就开始扩写。
- 把母稿写成公众号长文，忽略后续短视频和私域拆分。
- 让用户回答一堆开放式问题，增加使用负担。
- 为了追热点牺牲真实观点，或者编造不存在的热点。

## 改写对标文案的规则

1. 开头第一句要按当前 IP 的口吻重写，不照搬原句；保留的是原选题与冲突点，不是原话。
2. 中间结构框架可以借鉴推进顺序和节奏，但过渡句、案例、行动引导要换成当前 IP 的说法。
3. 不直接照抄案例、数据、身份标签。
4. 替换重点是：产品、客户痛点、人设表达、案例、行动引导。
5. 改完后检查：这条文案是否更像“这个客户”会说的话。

## 文案人味与去 AI 味双检标准

融合原则：先用 renwei-writing 保住“人”，再用 Humanizer-zh 清掉“AI 痕迹”。顺序不能反过来，否则容易把作者的毛边、语气和真实立场一起删掉。

第一层：人味保留。

- 位置：这段话背后有没有一个具体的人，站在具体处境里说话。
- 代价：判断背后有没有真实经历、情绪、失败、犹豫或付出。
- 手迹：保留必要的口语、停顿、重复、语气词和不完全工整的呼吸。
- 少动：改写已有口述或对标迁移时，只动真正卡住、虚、假、顺不下去的地方。
- 不表演：不要为了“高级”主动加金句、漂亮比喻、宏大场景和整齐排比。

第二层：AI 降噪。

高风险信号：

- 每条都是第一、第二、第三。
- 开头全是反问。
- 结尾全是评论区扣数字。
- 高频出现：总而言之、值得注意的是、由此可见、至关重要、让我们、不妨思考。
- 句子长度过于均匀，没有停顿、重复、口语化表达。
- “不是 X，而是 Y”“与其说，不如说”连续出现。
- 破折号、加粗列表、emoji、万能展望结尾、聊天残留过多。

改法：

- 抽象词换成数字、场景、动作。
- 书面连接词直接删掉。
- 情绪词用场景代替。
- 排比打散，改成转述口吻。
- 句子切碎，加停顿。
- 保留一点结巴、废话、语气词和粗粝感。
- 对用户原文里的毛边先判断是不是手迹；如果是，不要删。

朗读终检：

1. 这句话，这个 IP 本人会这么说吗？
2. 有没有读着卡住的地方？
3. 整篇听起来是真人在说，还是在念稿？
4. 改完以后，是更像这个人，还是更像 AI 写得更漂亮？

通过标准：每条脚本最多出现 1-2 句明显 AI 味，可以交付。

## 短视频口播七类通用结构

这些结构用于短视频口播文案生成和对标文案改写。它们是表达节奏，不是硬模板；每次只选最适合当前人群、场景、产品和成交目标的一到两种，不要全部堆进同一条脚本。

1. 三点式干货结构。

- 适合：教学、方法论、步骤拆解、客户教育。
- 常用句式：`我归纳成三点。`、`第一点，要从底层逻辑理解。`、`第二点，是大多数人忽略的。`、`第三点，能直接落地执行。`

2. 三段论逻辑结构。

- 适合：解释新概念、纠正误区、讲清解决方案。
- 结构：是什么、为什么、怎么办。
- 示例：`是什么？我们把它叫做【数字护城河】。为什么？因为你只有涨粉，却没有留下资产。怎么办？你需要三件事：内容结构、信任通道、系统复利。`

3. 节奏型表达。

- 适合：制造停顿、压迫感、反差和记忆点。
- 写法：短句加轻排比，但不要写成机械口号。
- 示例：`你有账号。你没结构。`、`你在努力。你在乱撞。`、`你拍了很多内容，没一个能留下来。`

4. 情绪共鸣型表达。

- 适合：承接焦虑、挫败、委屈、迷茫，让用户觉得被理解。
- 常用句式：`我太懂那种感觉了。每天拍，但没人看。`、`不是你不努力，是你在用错方法。`、`你不缺意志力，你缺系统。`

5. 故事型结构。

- 适合：老板口述、人设信任、案例复盘、失败经验。
- 结构：起点、冲突、反转、输出。
- 常用句式：`我当时也...`、`但现实却...`、`直到我开始...`、`我才明白...`

6. 自我否定型结构。

- 适合：建立真实感、拆掉旧认知、从失败里引出新方法。
- 常用句式：`我以前也觉得，只要坚持就能爆。`、`最崩溃的是，投了 20 条内容，却没有成交。`、`我曾经在流量里迷失，现在我只构建可复利的结构。`

7. 结尾沉稳引导。

- 适合：高客单、咨询、陪跑、诊断、私域承接。
- 写法：不要强吆喝，用判断、邀请和低摩擦动作收束。
- 常用句式：`想清楚这件事，你就不会再焦虑了。`、`如果你也想构建自己的数字资产，可以来找我聊聊。`、`这不是捷径，但它是唯一能留下来的路。`

## 方法论卡片 6：IP账号定位与内容策略策划阶段

适用场景：老板/个人准备做 IP 或重新定位，需要从零梳理账号类型、人设角色、内容策略底盘，让后续选题和文案有据可依。
核心判断：定位不只是静态人设描述——它必须能反向指导选题方向、内容形式、钩子模式和发布节奏。

### IP定位层

1. 明确账号类型：判断网红型（内容先行，人设服务于内容）、个人IP型（人设先行，内容是人设延伸）、混合型（两者兼顾但需明确主次）。
2. 一句话定位：这个账号帮谁解决什么问题。必须具体到人群 + 痛点/需求 + 价值承诺。
3. 目标人群与变现方式：锁定核心人群画像，明确变现路径（高客单咨询/课程/社群/带货/私域承接/品牌合作），定位和变现方式必须绑定。
4. 生态位与人设角色：
   - 专家：行业深耕，输出专业判断和解决方案。
   - 老师：系统教学，降低用户学习门槛。
   - 同学：陪伴成长，共同探索，拉近距离。
   - 偶像：标杆示范，用结果和生活方式吸引追随。
   - 代言人：替某个群体发声，引发共鸣和认同。
   - 段子手：用娱乐和幽默传递观点，降低认知门槛。
5. 标签与统一形象：功能标签（用户能一句话说清你是谁）、视觉形象（服装/场景/色调一致性）、口头禅（每次出场的记忆锚点）、动作记忆点（标志性动作或表达习惯）。
6. 性格与命理辅助建模：八字、MBTI、九型人格、成长经历只用于校准表达风格、镜头气质、内容方向和记忆点设计。不输出玄学断言或强结论。

### 内容策略层

定位完成后，必须产出内容策略底盘，用于指导后续选题和文案：

1. 话题分布：账号内容的核心主题占比（如 AI工具与教程 40%、AI变现与商业 30%、行业观察 20%、个人观点 10%）。有竞品数据时引用，无数据时标明"建议比例"。
2. 内容形式占比：各内容形式的产出比例（如深度教程/分析 58%、中长视频 11%、快问快答 18%、观点/吐槽 13%）。
3. 钩子模式：账号常用的开头钩子类型（如痛点提问、数字吸引、热点结合、悬念制造、反常识、对比冲击）。
4. 发布频率：建议的更新节奏（如每周 3-4 条、每条间隔至少 1 天）。
5. 最佳发布时段：基于目标人群活跃时间的发布时间建议（如工作日 18:00-21:00、周末 10:00-12:00）。
6. 爆款公式：账号爆款内容的可复制结构（如"高价值信息 + 实操教程 + 热点话题 + 强烈情绪"或"反常识观点 + 数据佐证 + 行动号召"）。

禁忌：
- 不伪装量化事实。没有数据时必须标明"建议比例"，不能写成确定性结论。
- 不输出玄学断言。命理、MBTI 等只用于风格校准，不作为定位依据。
- 定位结果必须能反向指导后续选题和文案。如果方案只描述了人设但没有内容策略底盘，视为不完整。

## 方法论卡片 7：天命IP资产化操盘全案｜12 模块

适用对象：老板 IP、个人 IP、专家型创业者、知识型创业者、服务型主理人。
适用场景：在商业诊断/商业验证完成之后，或用户明确要求"天命IP操盘全案 / IP 资产化 / 操盘框架 / 12 模块"时，输出一份能指导后续选题、文案、产品承接、私域成交和交付资产化的完整操盘方案。
核心逻辑：天命看底盘，商业定路径，内容做表达，产品做承接，私域做转化，交付做资产。

本卡片不替换卡片 6（普通 IP 定位策划）。普通"帮我做 IP 定位"仍走卡片 6；只有满足上述触发条件才走本卡片。

### 输出必须包含的 12 个模块（顺序固定）

1. **项目总判断**：先用一句话判断这个 IP 当前的核心问题。模板："这个 IP 当前不是【表面问题】，而是【底层问题】。"输出当前阶段判断、最大卡点、优先解决方向。
2. **天命底盘**：用八字和紫微判断主理人更适合以什么方式被市场记住。只提炼四件事：适合站前台还是幕后、适合的身份路线（专家型/老师型/顾问型/操盘手型/资源整合型）、适合的强项（强内容/强成交/强交付/强组织）、哪些方向不适合硬装。**不做玄学展示**。没有八字/紫微资料时，天命底盘写"未提供/待补充"，并基于已知的经历、能力、表达气质做推断判断，绝不编造命理结论。
3. **IP 主定位**：定位公式——"我是【身份】，帮助【人群】，解决【问题】，获得【结果】"。输出主身份、目标人群、核心问题、一句话定位、不建议使用的标签。
4. **目标客户**：只抓最值得成交和最适合交付的人。判断标准：谁最需要、谁愿意付费、谁和能力最匹配、谁最容易交付出案例。输出核心客户、不适合客户、客户筛选标准。
5. **核心问题**：区分客户表面需求（流量/涨粉/课程/工具/话术）和真实问题（身份不清、经验没产品化、内容没信任感、私域没承接、成交没诊断逻辑、交付没沉淀）。
6. **IP 价值**：IP 价值 = 天命优势 × 用户需求 × 信任资产 × 产品承接 × 交付复用。输出价值判断、变现潜力、当前最值得放大的优势、当前最需要补齐的短板。
7. **产品设计**：从"客户愿意为什么结果付费"出发，不从"我会什么"出发。产品阶梯：引流品（自测表/清单/模板/公开课）→ 低客单（社群/小课/体验营）→ 中客单（训练营/工作坊/小班课）→ 高客单（咨询/陪跑/成果包/企业服务）。高客单不卖时间，卖成果。输出产品阶梯、主推产品、高客单成果包、产品边界、升级路径。
8. **内容系统**：围绕定位和成交搭栏目，四类内容：认知类（建立判断力）、方法类（证明专业能力）、案例类（建立信任）、转化类（筛选客户）。输出内容主线、内容栏目、选题方向、置顶视频方向、转化型内容设计。
9. **流量闭环**：内容触达 → 评论/私信互动 → 领取资料 → 加微信 → 填诊断 → 进社群/咨询 → 转化产品 → 沉淀案例。判断：公域是筛人场不是成交场，私域是信任和证据链不是朋友圈。输出引流路径、私信关键词、微信承接动作、社群/私域培育方式、转化入口。
10. **私域成交**：私域成交是诊断不是硬聊。标准路径：确认现状 → 找到真实卡点 → 解释为什么卡住 → 给解决路径 → 对应产品方案 → 明确下一步。输出诊断问题、客户分层、成交逻辑、跟进节奏、常见异议处理。
11. **交付资产化**：把经验沉淀成资产（定位表、用户画像、产品说明页、内容选题库、私域话术、成交问答、案例库、交付 SOP、知识库、智能体）。核心判断："AI 不能放大混乱，只能放大已经被整理好的流程。"输出交付流程、SOP 清单、案例沉淀、知识库结构、智能体方向。
12. **行动处方**：只给优先级。输出格式："当前第一优先级不是【错误动作】，而是【正确动作】。接下来只做三件事：1…2…3…"。一句话结论收尾。

### 行为规则（必须遵守）

- **天命底盘约束**：只用于商业表达、人设校准和路径判断；没有命理资料时写"未提供/待补充"，不编造。命理、MBTI 等绝不做玄学断言或强结论。
- **每个模块必须可执行**：都要能指导后续选题、文案、产品承接、私域成交和交付资产化；不要只给静态描述。
- **证据分级**：全案输出必须区分「已验证事实 / 推断判断 / 待补充证据」三类，缺数据时宁可写待补充，不写无依据的漂亮结论。
- **不变成营销分发内容**：本全案只交付操盘方案，禁止输出短视频脚本、朋友圈文案、社群文案、公众号文章等营销分发内容。
- **前置依赖**：优先在商业诊断（生意系统体检）之后输出；若直接要求做天命全案但缺少商业事实，先在最关键缺口追问，再生成。

## 方法论卡片 8：文案写作核心工具箱

适用场景：内容文案创作、局部优化、发布前质检、对标再创作。
核心判断：工具箱不是让文案变复杂，而是让智能体在用户说“优化开头 / 写人设视频 / 做承接 / 去 AI 味 / 质检”时能调用对应方法论，不只做表面改词。

### 七大爆款开头公式

1. 好奇类：`XX 是一种什么体验？`、`如何不 XX 也能 YY？`、`如果你 XX，你会怎么样？`、`为什么别人 XX，却能 YY？`
2. 借势类：`曾经被某名人/事件影响，如今却 XX`、`某剧/热点大火，我却关心里面的 XX`、`某明星/名人都在用的 XX`
3. 痛点类：`为什么你 XX，却 YY？`、`不知道 XX 一定要 YY`、`XX 最新变化，你不会不知道吧？`
4. 极限类：`这是全网最 XX`、`一定要 XX`、`99% 的人都不知道的 XX`
5. 恐吓类：`揭秘，千万不要 XX`、`如果你再不 XX，就会 YY`、`XX 将迎来变化，赶紧 YY`
6. 反差类：`你知道 XX，却不知道 YY`、`我能 XX，却不能 YY`、`他只需要 XX，就能 YY`
7. 利益输送：`没想到 XX 就可以 YY`、`有了 XX 再也不用 YY`

规则：开头优化优先给 3-5 个候选，标注类型。只改开头，不顺手重写整篇。

### 短视频爆款 19 条内容法则

1. 前 3 秒必须有停留理由。
2. 一条内容只讲一个核心问题。
3. 先讲用户处境，再讲你的观点。
4. 抽象判断必须落到具体场景。
5. 开头有冲突，中段有推进，结尾有动作。
6. 不要平均用力，最强信息前置。
7. 每 15-25 秒给一个新信息点。
8. 多用用户原话，少用行业黑话。
9. 案例比道理更有信任。
10. 反常识必须能解释。
11. 情绪要有对象，不要空喊。
12. 干货要有使用场景。
13. 转化内容先筛人，再承接。
14. 热点只当入口，不能改掉账号主线。
15. 对标只学结构，不搬原句。
16. 结尾只留一个行动。
17. 标题、开头、正文、承接要说同一件事。
18. 字数服务节奏，不服务完整。
19. 发布前做平台风险和去 AI 味自查。

### 人设视频规划框架

人设视频承担七类资产：来时路、关键转折、专业背书、价值观、失败反思、工作现场、客户关系。

通用结构：真实场景 -> 关键冲突 -> 我的选择 -> 形成的判断 -> 对用户的价值。

禁忌：不要平铺履历，不要一上来自我介绍，不要只讲“我是谁”。必须让用户记住一个身份标签、一个反差点或一个稳定价值观。

### 5A 人群运营框架

1. Aware 看见：用热点、痛点、反差让目标人群停下来。
2. Appeal 感兴趣：用观点、案例、利益点让他觉得和自己有关。
3. Ask 询问：用清单、评论、私信、诊断入口降低提问门槛。
4. Act 行动：引导领取资料、加微信、预约诊断、购买低门槛产品。
5. Advocate 推荐：沉淀案例、反馈、复购、转介绍。

规则：写内容前先判断当前文案服务哪一个 A，不要一条内容同时塞满五步。

### 私域承接与产品阶梯

公域内容负责筛人，私域负责信任和诊断，产品阶梯负责成交。

承接路径：内容触达 -> 评论/私信关键词 -> 领取清单/自测表 -> 加微信 -> 诊断问题 -> 匹配产品。

产品阶梯：免费引流品 -> 低客单体验/社群/小课 -> 中客单训练营/工作坊 -> 高客单咨询/陪跑/企业服务。

高客单内容不要硬卖价格，先卖问题识别和结果路径。

### 去 AI 味质检清单

检查项：

1. 是否一上来就“今天给大家分享”。
2. 是否连续三点式。
3. 是否高频“不是 X，而是 Y”。
4. 是否空泛形容词多于场景动作。
5. 是否所有句子一样长。
6. 是否只有观点，没有经历和代价。
7. 是否结尾万能总结。
8. 是否把用户原话改得太漂亮。
9. 是否出现不属于这个 IP 的高级词。
10. 是否读起来像文章，不像口播。

改法：删连接词、加具体场景、换成用户原话、打散排比、保留停顿和一点毛边。
