# Topics Domain

- Entry: `/topic-planning`, topic APIs, daily report UI, and inspiration processing.
- Public surfaces: topic API contracts, presentation helpers, topic configuration, and inspiration processing service.
- Data ownership: topic candidates, selections, daily reports, source references, and topic-pool presentation state.
- Events: generate daily report, retry, select topic, save inspiration, and hand an authorized topic reference to AIM.
- Dependencies: project access, knowledge, hot signals, competitor evidence, and LLM infrastructure.
- Boundary: this domain produces topic evidence and choices; it does not invoke AIM editor internals or own content versions.
