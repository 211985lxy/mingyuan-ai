# Competitor Domain

- Entry: `/competitor`, competitor APIs, account workspace, discovery inputs, and monitored-video cards.
- Public surfaces: competitor API contracts and presentation helpers.
- Data ownership: monitored accounts, cached public works, refresh state, reports, and public web-research evidence.
- Events: discover, add monitor, refresh, analyze, extract public copy, and hand an authorized evidence reference to topics or AIM.
- Dependencies: account-scoped access, external public-data providers, OSS proxying, and observability infrastructure.
- Boundary: this domain supplies evidence, not final content decisions. Topics and AIM consume its contracts; competitor components must not import their UI or runtime internals.
